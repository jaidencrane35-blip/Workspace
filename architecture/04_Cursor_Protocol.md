# Cursor Protocol

Every implementation follows exactly this process.

1. Read Engineering Session Protocol (`17_Engineering_Session_Protocol.md`)

2. Read Blueprint

3. Read Current State

4. Read Engineering Ledger

5. Read Research Catalogue

6. Produce Plan

7. Wait if architecture changes

8. Implement

9. Validate

10. Update Ledger

11. Update Current State

12. Stop

The Engineering Session Protocol is mandatory immediately after this Cursor
Protocol and before Current State. It defines repository authority, session
startup, stop conditions, validation, and git discipline. Conversation history
is never authoritative.
