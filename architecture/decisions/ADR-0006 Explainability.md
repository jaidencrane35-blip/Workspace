# ADR-0006 - Explainability

Status: Accepted

---

# Decision

Workspace must be able to explain:

- What it is doing.
- Why it is doing it.
- Which permissions are being used.
- Which capability is responsible.

---

# Examples

Instead of:

Thinking...

Workspace displays:

Observing desktop...

Opening VS Code...

Waiting for Docker...

Permission required...

---

# Goal

Users should never wonder what Workspace is doing.
