# ADR-0002 - Integrate Before Reinvent

Status: Accepted

---

# Context

Engineering time is limited.

Many mature open-source projects already solve common problems.

---

# Decision

Workspace shall only implement custom software where it creates unique value.

All common capabilities must be researched before implementation.

---

# Examples

Integrate

- Speech recognition
- OCR
- Embedding engines
- Markdown
- AI SDKs

Build

- Companion orchestration
- Workspace management
- Permission model
- Memory orchestration
- Experience layer

---

# Consequences

Engineering effort focuses on Workspace itself.

Maintenance burden decreases.
