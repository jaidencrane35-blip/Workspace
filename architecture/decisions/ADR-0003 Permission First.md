# ADR-0003 - Permission First

Status: Accepted

---

# Context

AI companions can easily become intrusive.

Trust is the foundation of Workspace.

---

# Decision

Workspace requests permission before performing meaningful actions.

Permissions are explicit.

Revocable.

Explainable.

---

# Exceptions

Actions explicitly configured for automatic execution.

---

# Consequences

Higher user trust.

Predictable behaviour.

Reduced accidental automation.
