# Clarification Policy

Ask when the Operator cannot truthfully execute without inventing a target or placement.

| Signal | Behaviour |
| --- | --- |
| Missing placement (“move this window”) | Clarify where — no effect |
| Missing resize dimensions | Clarify size — no effect |
| Ambiguous multi-match (future) | Clarify which window/app — no effect |
| Clear single target | Execute without asking |

Never clarify by exposing Provider / Router terminology.
