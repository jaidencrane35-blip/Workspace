```
Engineering Complete
    ↓
```

Every future provider must satisfy **every stage** before permanent acceptance.

---

## Stage intent

| Stage | Meaning |
| --- | --- |
| Engineering Complete | Provider + port + permissions + Runtime registration |
| Repository Reassessment | Align with constitution / health / roadmap truth |
| Architecture Audit | Frozen pipeline; no provider coupling |
| Composition Audit | Independent usefulness + Operator composition |
| Conversation Audit | Usable through Conversation only |
| Natural Language Audit | Ordinary phrasing works (deterministic Intent) |
| Failure Audit | Truthful refusal; no invented success |
| Product Proof | Harness + Owner-usable path |
| Performance Validation | Still / status paths acceptable for desktop use |
| Launch Verification | Native app boots; terminate after verify |
| Commit / Push | One milestone commit; push `v2-dev` |
| Owner Review | Human acceptance |
| Permanent Closure | Health handoff; do not reopen except bugs |
| Next Program | Only after closure |
