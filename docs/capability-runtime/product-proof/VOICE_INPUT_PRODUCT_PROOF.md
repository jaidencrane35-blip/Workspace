## Owner checklist

### Voice

1. Mic control is easy to find beside the composer (larger control)  
2. After start, Voice pre-warms in the background  
3. Click mic → **Getting ready…** only if needed; **Listening** + pulse/wave only when capture has started  
4. Speak immediately — **first word should be captured** (no conscious pause)  
5. States progress clearly: Idle → Preparing → Listening → Recognizing → Processing → Finished  
6. Transcript submits like typed text  
7. Failures use ordinary language (+ Settings when relevant)  

### Conversation

8. **Open a new GPT tab** / **Open GPT** → ChatGPT in browser (**not** `gpt tab.exe`)  
9. **Open YouTube beside ChatGPT** → open + arrange (Operator composition)  
10. **Open ChatGPT in another browser window** → browser open  
11. **Close YouTube** / **Bring Chrome forward** / **Open my recent browser**  
12. **Open Settings** → Windows Settings  
13. **Take a capture of our chat** → screenshot this window  
14. Unsupported (truthful): **Close this browser tab**, **Minimize all applications**, **Set speaker volume to 50%**, **Transcribe this conversation**  
15. Unsupported replies vary and suggest nearby desktop help — not identical canned churn  
16. No Provider / Runtime / WinRT terminology
