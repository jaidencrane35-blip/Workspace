## Objective

Introduce the deterministic **Receive Permission** decision stage of Observe → Learn → Suggest → Permission → Automate.

After Sprint 20 proposals (`Suggestion`), the user must be able to **Accept** or **Reject** a proposal through the existing intent → capability → permission → command pipeline. Acceptance is an audited **decision**, never Automate-stage execution. There is still no AI, suggestion persistence table, Permission Gateway UI, or automation engine.

---

## Architecture Decision

**Decision-only mutation commands; audit as durable decision history.**

```
GetSuggestions (Pending proposals)
        │
        ▼
AcceptSuggestion / RejectSuggestion   ← MutationCommand
        │
        ▼
Intent registry → Capability (audit.write) → Policy → PermissionGate → execute
        │
        ▼
Audit: command.executed + metadata { suggestion_id, decision }
        │
        ▼
GetSuggestions suppresses decided ids (derived filter; no suggestion store)
```

### Sprint decisions (recorded here; no separate Decision Log entry required)

1. **Accept semantics:** Decision-only. Does **not** dispatch CreateZone / UpdateLayout / etc. Automate remains a later stage and requires a future proposed-action binding on `Suggestion`.
2. **Capability:** Reuse `audit.write` — decisions mutate governance history, not workspace entities.
3. **Persistence:** No suggestion table. Decision durability is the existing audit trail; list suppression is audit-derived.
4. **Stale ids:** Fail closed (`SuggestionValidation` / not found) when the id is no longer currently derived or already decided.
5. **Approval types** (one-time / session / persistent) deferred with the real Permission Gateway.

## Deliverables

### Domain
- `Suggestion::accept` / `Suggestion::reject` (Pending-only transitions)
- `find_pending_suggestion`
- `SuggestionError::{NotFound, InvalidTransition}`
- `ActionIntentCategory::Suggestion`
- Registry entries: `accept-suggestion`, `reject-suggestion`

### Kernel
- `AcceptSuggestion`, `RejectSuggestion` mutation commands
- `MutationCommand::audit_metadata` (optional; used for decision detail)
- `SuggestionService::resolve_pending` + audit-based decided-id suppression
- `CommandHandler::{accept_suggestion, reject_suggestion}`

### IPC
- `accept_suggestion`, `reject_suggestion`
