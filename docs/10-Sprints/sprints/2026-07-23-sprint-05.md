## Objective

Establish the first Workspace domain foundation: entities, repository pattern, kernel services, and IPC — without UI, canvas, or layout engine.

---

## Architecture

```
React (unchanged display — no workspace UI this sprint)
    ↓ IPC (IpcResponse)
Tauri Commands
    ↓
CommandHandler (CreateWorkspace, GetWorkspace)
    ↓
WorkspaceService
    ↓
Repositories (WorkspaceRepository, ZoneRepository)
    ↓
SQLite (002_workspace.sql)
```

### Ownership

| Layer | Owns |
|-------|------|
| `workspace-domain` | Entity models + validation |
| `workspace-database` | Repositories + SQL |
| `workspace-kernel` | Services, commands, events |
| React | Display only (no new workspace UI) |

---

## Domain Model

- **Workspace** — id, name, created_at, updated_at
- **Zone** — id, workspace_id, name, position_metadata (placeholder)
- **ApplicationReference** — id, workspace_id, name, identifier (placeholder)
- **WidgetReference** — id, workspace_id, name, widget_type (placeholder)

---

## Schema (`002_workspace.sql`)

Tables: `workspaces`, `zones`, `applications`, `widgets`

No AI, automation, permission, or layout engine tables.
