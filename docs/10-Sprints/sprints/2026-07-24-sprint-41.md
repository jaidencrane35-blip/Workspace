## Objective

Make desktop application launch a **governed action** that must pass through Permission Gateway before any OS spawn.

---

## Architecture

```
User / Diagnostic
      ↓
LaunchApplication (MutationCommand)
      ↓
CommandPipeline
      ↓
PermissionGateway (application.launch)
      ↓
Allow → ApplicationLaunchService → windows-integration::ProcessLauncher
Deny / ApprovalRequired → no spawn + audit
```
