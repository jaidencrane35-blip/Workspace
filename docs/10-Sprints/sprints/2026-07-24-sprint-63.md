## Goal

Connect model providers into planning safely: candidates → proposals → gateway.

## Delivered

- `ModelProviderRegistry` + routing (availability/capability; no permission influence)
- Planning uses provider candidates via `ModelProviderService::plan_from_context`
- Audits: `ai.model.provider_selected|requested|response_received|failed`
- Safe failure for unavailable / unsupported providers
- Operator Console diagnostics + CASE 1–7 boundary tests

## Boundary proved

Provider → AI output → Proposal system → Permission Gateway  
Provider ✕ Execution / permission grants
