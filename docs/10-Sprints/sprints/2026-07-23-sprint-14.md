## Objective

Create a derived, read-only workspace state projection layer that aggregates authoritative domain state into a single `WorkspaceSnapshot` for future consumers (Canvas, AI, plugins, search, automation).

---

## Architecture

```
Authoritative Domain State
  Workspace / Zone / Application / Widget / Layout / Graph
              ↓
   WorkspaceProjectionService (orchestration only)
              ↓
        WorkspaceSnapshot (derived, disposable)
              ↓
     Future Consumers (Canvas, AI, Plugins, …)
```

---

## Architecture Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Projection ownership | `WorkspaceProjectionService` | Coordinates existing services; does not own state |
| Domain model | Lightweight summaries + `ResourceRef` | Avoids duplicating full entities or persistence models |
| Graph relationships | `ProjectionRelationship` from `GraphService::list_edges_from` | Topology only; no spatial data |
| Layout in snapshot | Optional `layout_id` + `LayoutPlacementSummary` | Layout remains authoritative in `LayoutService` |
| Service list APIs | Added `list_by_workspace` to Zone/Application/Widget services | Projection must not query repositories directly |

---

## Persistence Decision

**No projection persistence.**

`WorkspaceSnapshot` is derived state rebuilt on demand from authoritative domain services. No repository, cache, or SQLite tables were added. Projections are disposable and non-authoritative.

---

## Governance Decision

**`GovernanceClass::Ungoverned` for local human reads** (DEC-017).

`GetWorkspaceSnapshot` mirrors `GetWorkspace` and `GetLayout`: it aggregates non-sensitive workspace resource reads. Non-human actors (`System`, `Automation`, `Plugin`, `AI`) remain governed via `read_is_governed`. Required capability: `workspace.read`.

---

## Audit Decision

**No audit event for normal snapshot reads.**

Snapshot reads are high-frequency, derived, and non-mutating. Audit noise would outweigh value. Governed non-human reads follow existing pipeline audit rules when policy requires; no dedicated snapshot audit event was added.

## Remaining Risks

| Risk | Mitigation |
|------|------------|
| Snapshot staleness | Consumers must treat `generated_at` as point-in-time; re-fetch for freshness |
| Cross-domain inconsistency | `WorkspaceSnapshot::validate` rejects orphan graph/layout references |
| Performance at scale | No caching yet; add only when measured need exists |
| Capability granularity | Uses `workspace.read`; split to `workspace.snapshot` only if future consumers need it |
