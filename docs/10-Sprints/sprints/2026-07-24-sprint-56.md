| Field | Value |
|-------|-------|

## Goal

Create structured multi-action plans that remain separate from permissions and execution authority.

## Delivered

- Domain `AiOrchestratedPlan` / `AiPlanStep` with plan + step lifecycle states
- Sequential dependencies (step N depends on N−1)
- In-memory plan store on the kernel (diagnostic, non-authoritative)
- `ai.plan.created` audit

## Non-goals

Autonomous execution, AI permissions, tool calling, agent loops.
