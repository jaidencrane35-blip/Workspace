## Objective

Final permission architecture audit and consolidation. No new product features. Confirm future AI / plugin / automation actors can only enter through the existing authority path.

---

## Audit findings → seals

| Finding | Severity | Seal |
|---------|----------|------|
| `ApplicationLaunchService` / `PermissionApprovalService` were public crate exports | High | `pub(crate)` types + methods; removed from `kernel` public re-exports |
| Decide used unconditional `UPDATE` (double-decide race) | Medium | `decide_if_pending` with `WHERE status = 'pending'` |
| Grant match treated `command_name = None` as wildcard | Medium | Require exact command match |
| Missing boundary tests | Medium | Non-LocalUser decide, double-decide, audit fields, kernel-default AI launch |
| Docs incomplete for “how is something allowed?” | — | [`PERMISSION-ARCHITECTURE.md`](../../07-Security/PERMISSION-ARCHITECTURE.md) |
