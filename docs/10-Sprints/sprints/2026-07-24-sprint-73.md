## Outcome

Trigger events and a TriggerEvaluator produce explainable Intent Proposals from approved Automation Contracts. No schedulers, workers, background services, or automatic execution.

See [Governed Trigger Evaluation](../../05-AI/GOVERNED-TRIGGER-EVALUATION.md).

## Governance path preserved

```
Trigger → Evaluate → Proposal → (optional accept) → Prepare Intent
  → Command Pipeline → Permission Gateway → Execution
```

## CASE coverage

1. Trigger events can be created  
2. Evaluation finds matching contracts  
3. Paused contracts ignored  
4. Revoked contracts ignored  
5. Invalid fingerprints rejected  
6. Scope mismatches rejected  
7. Evaluation cannot execute  
8. Evaluation cannot bypass Permission Gateway  
9. Intelligence displays but cannot modify  
10. Accepted proposals still require normal governance
