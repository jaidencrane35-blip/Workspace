## Purpose

Establish **why** an action is performed and **what authority** it requires — without changing runtime behaviour, adding UI, or enforcing capabilities.

Sprint 08 answered **who**. Sprint 09 adds **intent**, **capability identifiers**, and **policy evaluation contracts**.

---

## Architecture

```
ActorContext + IntentContext
    ↓
CommandContext { capability_set, permission_policy, permission_gate }
    ↓
CommandPipeline
    ├─ PolicyContext → PermissionPolicy (AlwaysAllowPolicy)
    ├─ PermissionRequest { actor, intent, capability, subject }
    ├─ PermissionGate (AllowAllPermissionGate — unchanged behaviour)
    └─ AuditService (intent_type + capability)
```

### Active intent types (Sprint 09)

| Intent | Used when |
|--------|-----------|
| `UserRequest` | IPC-originated commands |
| `SystemStartup` | Kernel initialization lifecycle events |
| `SystemShutdown` | Kernel shutdown |

Placeholders (`AISuggestion`, `Automation`, `PluginRequest`, etc.) exist in the domain model only.

### Standard capabilities (identifiers only)

| Capability | Scope |
|------------|-------|
| `workspace.read` / `workspace.write` | Workspace |
| `settings.read` / `settings.write` | Settings |
| `audit.read` / `audit.write` | Audit |
| `system.startup` / `system.shutdown` | System |

Capabilities are **not evaluated or enforced** in Sprint 09.

---

## Policy model (`packages/kernel/src/policy/`)

| Type | Role |
|------|------|
| `PermissionPolicy` | Evaluates a `PolicyContext` |
| `PolicyEvaluator` | Delegates to a policy (composite rules later) |
| `PolicyContext` | Actor + intent + capability + command + subject |
| `PolicyDecision` / `PolicyResult` | Allow or deny with reason |
| `AlwaysAllowPolicy` | Default — mirrors `AllowAllPermissionGate` |

---

## Execution pipeline changes

- `CommandContext` extended with `intent_context`, `capability_set`, `permission_policy`
- `MutationCommand::required_capability()` declares requested capability
- Pipeline evaluates policy before permission gate (both allow-all today)
- Audit records `intent_type` and `capability` (migration `005_audit_intent_capability.sql`)
