## Outcome

`WorkspaceWorkingStyleService` projects Intelligence + Session + Experience + Work Context + Navigation + Milestones into `WorkspaceWorkingStyleState`. Intelligence embeds `working_style` after Milestones. Attention / RE / Adaptation / Session / Navigation / Experience may reference Working Style as evidence only. Observed behaviour stays separate from explicit preferences. No persistence, ML, surveillance, prediction, autonomous adaptation, execution, or Gateway changes.

See [Workspace Working Style Model](../../05-AI/WORKSPACE-WORKING-STYLE-MODEL.md).

## Surfaces

- **Work** — How this Workspace usually works / Common Workflows / Typical Contexts / Frequent Arrangements / Observed Patterns / Explicit Preferences / Observed vs Preferred
- **Assistant** — explains Working Style only; never claims certainty
- **Operator** — Generate / Inspect / Compare / Validate
