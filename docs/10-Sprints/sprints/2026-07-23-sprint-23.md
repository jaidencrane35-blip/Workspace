## Objective

Create a safe bridge between **approved suggestions** and **intent creation** without executing commands or introducing automation.

After Sprint 22, lifecycle visibility exists for accept/reject decisions. Sprint 23 adds the next governance boundary: an accepted suggestion may produce a validated `SuggestionIntentRequest`, stopping before command execution.

This sprint is **not** automation.

---

## Architecture Decision

**Option A: Generate intent request only**

```
Accepted Suggestion (audit-backed)
    ↓
SuggestionIntentService (orchestration)
    ↓
map_suggestion_type_to_intent (static domain mapping)
    ↓
IntentExecutionService::validate_request
    ↓
SuggestionIntentRequest
    ↓
CreateSuggestionIntentRequest (governed mutation + audit)
    ↓
[Future] CommandPipeline execution boundary
```

Approval grants permission to create an actionable request — not permission to bypass governance or execute.

---

## Persistence Decision

**None.** No suggestion-intent table, repository, or migration. Bridge records are stored through existing audit metadata on `CreateSuggestionIntentRequest` (`bridge: intent_request_created`). Durable acceptance remains in AcceptSuggestion audit events.

---

## Governance Decision

**Governed mutation** through `CommandPipeline` with **`audit.write`** capability and **`PermissionSubject::System`**. Same governance boundary as Accept/Reject decisions. No bypass paths from `SuggestionService` to command execution.

---

## Audit Decision

`CreateSuggestionIntentRequest` records:

```json
{
  "suggestion_id": "...",
  "intent_id": "create-zone",
  "bridge": "intent_request_created"
}
```

Acceptance is verified by scanning prior `AcceptSuggestion` audit records. Rejected or pending suggestions fail closed.

---

## IPC Decision

**Deferred.** No current UI consumer for the bridge command. `CommandHandler::create_suggestion_intent_request` is available for future IPC when a consumer exists. Pattern will mirror existing suggestion commands (IPC → CommandHandler → CommandPipeline).
