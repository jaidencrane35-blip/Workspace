## Objective

Create the deterministic **Context** boundary of Observe → Learn → Suggest → Permission → Automate.

`WorkspaceContext` assembles the existing derived read layers into a single, read-only structure so future ("Suggest") stages have one coherent input. This is a deterministic composition — no AI, suggestions, recommendations, memory, embeddings, or persistence.

---

## Architecture Decision

**Deterministic context boundary composing existing derived layers.**

```
Projection (state) ─┐
Observations (activity) ─┤
Analytics (metrics) ─┤→ WorkspaceContextService → WorkspaceContext
Capability discovery (authority) ─┘
                                        ↓
                    GetWorkspaceContext (governed) → IPC → future consumers
```

The service orchestrates existing services (`WorkspaceProjectionService`, `ObservationService`, `WorkspaceAnalyticsService`, `CapabilityResolver`) and validates the composition via the pure domain type. It adds no new read logic, no mutation, and no persistence. `ResourceRef` remains the canonical workspace identity and is asserted consistent between the context and its snapshot.

---

## Context Domain Model

`WorkspaceContext { generated_at, workspace, snapshot, observations, metrics, capabilities }`

- `workspace: ResourceRef` — canonical identity, must equal `snapshot.workspace`.
- `snapshot: WorkspaceSnapshot` — Sprint 14 state.
- `observations: Vec<Observation>` — Sprint 17 activity.
- `metrics: WorkspaceMetrics` — Sprint 18 analytics.
- `capabilities: CapabilityDiscovery` — Sprint 16 authority.
- `validate()` enforces a non-empty timestamp, `ResourceRef` identity, and delegates to each component's own validation.

---

## Persistence Decision

**None.** No context table, memory store, cache, embeddings, or vector database. The context is composed on demand from already-derived layers (themselves derived from authoritative state and the audit trail).

---

## Governance Decision

**`GovernanceClass::Governed`** for all actors. Context combines activity history, workspace state, and capability information (sensitive). Required capability: **`audit.read`** — reusing the most sensitive input's capability rather than creating a new permission model. Permission subject: `System`.

---

## Audit Decision

**No new audit event type.** Governed context reads follow the existing pipeline governed-read path, consistent with `GetObservations` / `GetWorkspaceMetrics` / `GetAuditHistory`. No audit pollution.

---

## IPC Decision

**Added `get_workspace_context`** — additive read endpoint taking `workspace_id` + optional `limit`, returning `IpcResponse<WorkspaceContext>`. No internal service details exposed beyond the composed read models.

## Remaining Risks

| Risk | Mitigation |
|------|------------|
| Context inherits coupling of its component layers | Accepted; composition-of-derived-reads, no new authority or storage |
| Cost of composing four reads per call | On-demand only, bounded `limit` (default 200, max 500); cache only when a measured consumer exists |
| Scope creep toward Suggest/AI | Prohibited by design: deterministic composition only, no inference |
