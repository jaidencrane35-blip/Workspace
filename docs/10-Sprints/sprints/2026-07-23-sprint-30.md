## Objective

Extend Sprint 29 reconciliation to a **bounded list read projection** so consumers can ask:

**"What are the current interpreted states of recent executions?"**

```
Audit → ExecutionOutcomeService → reconcile_execution_states (pure)
  → ExecutionReconciliationService::list_recent

```

Reuses Sprint 29 `ExecutionReconciliation` and precedence rules per id.
