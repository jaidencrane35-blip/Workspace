## Objective

Create the internal communication foundation to decouple UI, kernel, services, and future workers through a command layer and event bus — without building product features.

---

## Architecture

### External (IPC)

```
React UI  →  Tauri commands (IpcResponse)  →  CommandHandler  →  Services  →  Database
```

### Internal (kernel)

```
CommandHandler  →  Services  →  Database
       ↓
   EventBus  →  Subscribers (logging, future modules)
```

### Ownership rules

| Layer | Responsibility |
|-------|----------------|
| React | Display only; no business logic |
| Tauri commands | IPC translation; no direct database access |
| Command layer | State-changing operations; validation; event emission |
| Event bus | Internal notifications; synchronous; thread-safe |
| Services | Database operations; isolated from UI |
| Database | Persistence only |

---

## Domain Events (Sprint 04)

| Event | Name | When |
|-------|------|------|
| `WorkspaceStarted` | `system.workspace.started` | InitializeWorkspace begins |
| `WorkspaceReady` | `system.workspace.ready` | Kernel reaches ready |
| `WorkspaceShutdown` | `system.workspace.shutdown` | Shutdown command |
| `SettingsChanged` | `system.settings.changed` | UpdateSettings succeeds |

---

## Commands (Sprint 04)

| Command | Type | Description |
|---------|------|-------------|
| `InitializeWorkspace` | State-changing | Database + configuration startup |
| `UpdateSettings` | State-changing | Validated settings update |
| `ShutdownWorkspace` | State-changing | Lifecycle shutdown + event |

Read-only IPC (`get_workspace_status`, `get_workspace_health`, `get_settings`) uses kernel queries, not the command layer.

---

## Scope

### In scope

- `EventBus` with typed `DomainEvent` publishing/subscription
- Command trait and `CommandHandler`
- Refactor Tauri `update_settings` through command layer
- InitializeWorkspace emits lifecycle events
- Command/event logging observability

### Exclusions

- AI, automation, plugins, spatial canvas, layouts, overlays
- Windows APIs, background agents, cloud services
- Async event bus, telemetry, plugin/AI event types
