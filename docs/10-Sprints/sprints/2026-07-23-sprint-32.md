---

## Objective

Close the front-to-back gap for the governed execution loop:

```
Workspace → Zones → Suggestions → Accept
  → Intent bridge → Execute → Outcomes / States / Context
```

Wire Sprint 23–30 kernel commands through Tauri IPC and expose an operator console that exercises the path (no Spatial Canvas).

---

## Architecture Decision

**Option A: Thin IPC + diagnostic operator UI**

- New `execution.rs` IPC module mirrors `CommandHandler` for S23–S30
- Existing suggestion/context/workspace IPC reused
- React operator console uses `invokeIpc` only — no redesign of governance

---

## Persistence Decision

**None new.** Operator UI stores active workspace id in `localStorage` only.

---

## Governance Decision

**No new capabilities.** IPC forwards to existing governed commands (`audit.read` for reads; existing mutation permissions for accept/intent/execute/cancel).

---

## Audit Decision

**No new event types.** Existing command audit trails remain source of truth.
