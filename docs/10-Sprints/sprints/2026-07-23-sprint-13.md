## Architecture

```
Graph (topology)     Layout (presentation)     Canvas (future)
"What exists?"   →   "Where is it?"        →   "How is it displayed?"
```

- **LayoutService** references `ResourceRef` only; no graph traversal or mutation
- **Commands** validate graph node existence via `GraphService.exists` before updating layout nodes
- **LayoutService** validates spatial constraints (sizes, coordinates, viewport, duplicate nodes)
