## Objective

Replace AllowAll execution defaults with a real **Permission Gateway** authority seam so future desktop actions, launches, automation, plugins, and AI agents cannot silently bypass authorization.

---

## Architecture

```
CommandPipeline
      ↓
PermissionGateway
      ├─ CapabilityBoundPolicy  (explicit allow / default deny)
      ├─ StandardPermissionGate (LocalUser/System allow; non-human → ApprovalRequired)
      └─ Audit (permission.allowed | permission.denied | permission.approval_required)
      ↓
Allow → Execution
Deny / ApprovalRequired → PermissionDenied (no execution)
```

### Model

| Concept | Meaning |
|---------|---------|
| Actor | Who requests (`Actor` / `ActorType`) |
| Intent | Why (`Intent` / `IntentType`) |
| Resource | What (`PermissionSubject`) |
| Action | Command + required `Capability` |
| Decision | Allow / Deny / ApprovalRequired |

### Defaults

| Component | Phase 1 | Phase 2 (now) |
|-----------|---------|----------------|
| Policy | `AlwaysAllowPolicy` | `CapabilityBoundPolicy` |
| Gate | `AllowAllPermissionGate` | `StandardPermissionGate` |
| Non-human caps | Same as local user | Empty set (default deny) |

`AlwaysAllow*` retained for unit tests only.
