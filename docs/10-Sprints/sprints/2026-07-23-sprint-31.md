| Field | Value |

---

## Objective

Enrich `WorkspaceContext` with recent reconciled execution states so trusted consumers can ask:

**"What is the current interpreted state of recent executions?"**

Without a separate `GetExecutionStates` call.

This is read-only context composition. It is **not** AI memory, automation, runtime control, or persistence.

---

## Architecture Decision

**Option A: Derived execution state context (mirrors Sprint 26)**

```
Audit
  ↓
ExecutionOutcomeService
  ↓
ExecutionReconciliationService::list_recent
  ↓
WorkspaceContext.execution_states (additive field)
  ↓
GetWorkspaceContext (existing governed read)
```

Reuses Sprint 29–30 reconciliation types and precedence rules. No redesign of governance boundaries.

---

## Persistence Decision

**None.** States are derived on demand from audit → outcomes → reconciliation fold.

---

## Governance Decision

**No new capability, permission, or command.** Enrichment inside the existing `WorkspaceContextService::build` path. `GetWorkspaceContext` already governs the composed read (`audit.read`).

---

## Audit Decision

**No new audit event types.** Audit remains the durable source of truth.

---

## IPC Decision

**Deferred.** No new Tauri surface; existing `GetWorkspaceContext` IPC path gains the field when consumers wire it.
