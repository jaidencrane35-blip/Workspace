## Objective

Turn `ApprovalRequired` into a durable human control loop: pending request → decision → allow-once grant → retry allowed.

## Flow

```
Non-human action
  → Gateway ApprovalRequired
  → Persist pending request
  → LocalUser DecideApproval(allow_once|deny)
  → Allow once: CapabilityGrant(active)
  → Retry: merge grant → Allow → consume grant
```
