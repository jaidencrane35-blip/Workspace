## Objective

Harden runtime governance boundaries before adding resource entities. No user-facing features, no Resource Registry, no UI changes.

Architecture audit identified missing seams for permission, uniform command execution, typed identity, transactions, and safe event dispatch.

---

## Architecture

```
React (unchanged)
    ↓ IPC (IpcResponse)
Tauri Commands
    ↓
CommandHandler
    ↓
CommandPipeline ──→ PermissionGate (AllowAllPermissionGate)
    ↓
MutationCommand / QueryCommand
    ↓
Services
    ↓
Repositories (typed IDs)
    ↓
Database::transaction() (where needed)
    ↓
SQLite
```

### Bootstrap exception

`InitializeWorkspace` remains a bootstrap command (runs before kernel is ready). All post-ready mutations route through `CommandPipeline` or `CommandHandler::shutdown` (permission-checked).

## 1. Command Execution Boundary

| Component | Location | Role |
|-----------|----------|------|
| `CommandContext` | `packages/kernel/src/commands/context.rs` | Shared runtime deps for commands |
| `CommandPipeline` | `packages/kernel/src/commands/pipeline.rs` | Uniform mutation/query dispatch |
| `MutationCommand` | `packages/kernel/src/commands/trait.rs` | State-changing commands |
| `QueryCommand` | `packages/kernel/src/commands/trait.rs` | Read-only commands |

**Mutations through pipeline:** `CreateWorkspace`, `UpdateSettings`

**Shutdown:** `CommandHandler::shutdown` — permission gate + lifecycle (requires `&mut` kernel)

---

## 2. Permission Gate Seam

| Component | Location |
|-----------|----------|
| `PermissionGate` trait | `packages/kernel/src/security/gate.rs` |
| `AllowAllPermissionGate` | `packages/kernel/src/security/allow_all.rs` |
| `PermissionRequest` / `PermissionSubject` | `packages/kernel/src/security/gate.rs` |

Every mutation checks the gate before execution. Default: allowed. Future: user approval, AI suggestions, automation policy.

`KernelError::PermissionDenied` maps to IPC `permission_denied`.

---

## 3. Typed Domain Identifiers

| Type | Location |
|------|----------|
| `WorkspaceId`, `ZoneId`, `ApplicationId`, `WidgetId` | `packages/domain/src/ids/mod.rs` |

- Strongly typed newtypes with serde transparent serialization (JSON remains string)
- `generate()` via UUID v4
- Validation rejects empty/whitespace IDs

Entities, repositories, and services updated to use typed IDs.

---

## 4. Database Transaction Boundary

| Component | Location |
|-----------|----------|
| `Database::transaction()` | `packages/database/src/connection.rs` |
| `Transaction` | `packages/database/src/transaction.rs` |

Uses `BEGIN IMMEDIATE` / `COMMIT` / `ROLLBACK` — works with existing `&Database` references.

`WorkspaceService::update_name` uses transactional update + read.

`DatabaseError::NotFound` added for transactional not-found paths.

---

## 5. EventBus Safety

`EventBus::publish` now:

1. Acquires subscriber list lock
2. Clones handlers
3. Releases lock
4. Invokes handlers

Prevents deadlock on nested publish and allows safe subscriber mutation during dispatch.

---

## 6. Registry Naming Decision

**Decision:** The term **Registry** is reserved for runtime/service tracking (`ServiceRegistry`).

Future resource persistence must **not** use `ResourceRegistry`. Use sibling domain services instead:

- `ZoneService`
- `ApplicationService`
- `WidgetService`

Or a single `ResourceService` if aggregation is needed — but not nested under `WorkspaceService`.
