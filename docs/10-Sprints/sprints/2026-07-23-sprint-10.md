## Purpose

Close the foundational gaps identified by the post–Sprint 09 architecture audit **before** building Resource Services and the Workspace Graph. Scaffolding only — no user-facing features, no enforcement changes.

Implements two Decision Records and one integrity fix:

- **[DEC-016](../../09-Decisions/DECISION-LOG.md) — Resource Addressing Model**
- **[DEC-017](../../09-Decisions/DECISION-LOG.md) — Read Governance Policy**
- Foreign key enforcement (audit finding C1)

---

## DEC-016 — Resource Addressing Model

- New domain types (`packages/domain/src/resource/`): `ResourceKind`, `ResourceId`, `ResourceRef`, and an `Addressable` trait.
- Typed IDs remain for entity-internal type safety; `ResourceRef { kind, id }` is the cross-cutting address for permissions, audit, IPC, and the future graph.
- `ResourceRef` serializes as `{ kind, id }`; `kind:id` (`Display`) is the canonical audit/log form.
- `PermissionSubject` redefined from a closed `System | Settings | Workspace` enum to `System | Resource(ResourceKind)`. Settings maps to `System` (settings-as-system); `CreateWorkspace` maps to `Resource(Workspace)`.
- The four entities (`Workspace`, `Zone`, `ApplicationReference`, `WidgetReference`) implement `Addressable`.

## DEC-017 — Read Governance Policy

- `QueryCommand` now declares `permission_subject()`, `required_capability()`, and `governance_class()` (`Ungoverned | Governed`).
- `execute_query` applies read governance: **governed** reads (non-human actors, or sensitive kinds) run policy + gate (allow-all today) and are audited; **ungoverned** local-human reads bypass governance and are not audited.
- Read classification: `read_is_governed(actor_type, class)` = `Governed` class **or** non-`LocalUser` actor.
- `GetWorkspace` → `workspace.read`, `Ungoverned`. `GetAuditHistory` → `audit.read`, `Governed` (sensitive).
- Enforcement remains allow-all (per Sprint 09); only the governance/audit path is wired.

## Foreign key enforcement (C1)

- `PRAGMA foreign_keys = ON` applied on every connection (file + in-memory) in `packages/database/src/connection.rs`.
- Migration-declared `ON DELETE CASCADE` and referential integrity are now enforced — a prerequisite for the relational Workspace Graph.
