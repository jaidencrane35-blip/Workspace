## Outcome

`WorkspaceMilestoneService` projects Intelligence + Session + Experience + Work Context + Navigation into `WorkspaceMilestoneState`. Intelligence embeds `milestones` after Navigation. Attention / RE / Adaptation / Session / Navigation may reference Milestones as evidence only. No persistence, planning, scheduling, auto-completion, execution, or Gateway changes.

See [Workspace Milestone Engine](../../05-AI/WORKSPACE-MILESTONE-ENGINE.md).

## Surfaces

- **Work** — Current Milestone / Progress Overview / Upcoming / Blocked / Completed / Dependencies
- **Assistant** — explains Milestones only
- **Operator** — Generate / Inspect / Compare / Validate

All `authority_effect: none`.

## Tests (CASE 1–10)
